## O que o script faz

Gera o `MTCAIXA.txt` de **PAGAMENTO DE PRÊMIO** (lançamento 960) para importar no sistema:

1. Lê o arquivo de operações da **CETIP** (.txt, separado por TAB) e filtra `Tipo Operação = PAGAMENTO DE PRÊMIO`, comparando sem acento.
2. Monta a **query de posição LZ** no Athena só com os títulos encontrados (`LASTRO.codigo_clearing IN (...)`) e executa via ODBC (`executar_query_athena`).
3. Cruza as duas bases por **conta e título**: `Conta` da CETIP só com os dígitos (`2385400-6` → `23854006`) = `cd_cetip`, e `Título` = `codigo_clearing`.
4. **Valor lançado = valor da CETIP.** Se houver mais de uma operação para a mesma conta e título, cada uma recebe `TRUNC(qt × PU, 2)` e a sobra de centavos vai para a maior, fechando exatamente com o total da CETIP.
5. **Data de lançamento e de liquidação** = `Data Liquidação` **da CETIP** (dd/mm/aaaa).
6. **Controle** no console: compara a quantidade da posição com a da CETIP e `qt × PU` com o valor da CETIP. Os status são `OK`, `DIVERGE QTD` (principal alerta), `DIVERGE VALOR` e "sem posição" (título que não é lançado).
7. Grava o `MTCAIXA.txt`: TAB, **cp1252**, CRLF, 18 colunas, uma linha por operação.

## Pontos de atenção que já foram tratados (não quebrar)

- O Athena devolve os nomes das colunas em minúsculo. O script aplica `.str.lower()` nos nomes.
- O `cd_cetip` pode vir como número (`23854006.0`). A função `so_digitos` trata isso.
- O arquivo da CETIP pode vir em UTF-8 ou cp1252. A função `ler()` testa os dois.
- A descrição leva "PRÊMIO" com acento, e por isso a saída é gravada em cp1252.
- Só entram posições com `quantidade_total > 0`.

## 4. Fluxo

1. **CETIP** → lê o `.txt` (tab) e filtra `Tipo Operação = PAGAMENTO DE PRÊMIO`.
2. **Query** → monta a query de posição LZ com os títulos do passo 1 (`codigo_clearing IN (...)`) e executa via ODBC.
   - Pega a última posição de cada carteira na janela D-1 até D-5 dos dias com posição (sem contar hoje).
   - Filtra `sigla_sistema_origem = 'LZ'` e `indicador_publico_privado = 'I'`.
3. **Cruzamento** → `Conta` CETIP (só dígitos) = `CD_CETIP` e `Título` = `codigo_clearing`.
4. **Valor lançado** → valor da CETIP.
   - 1 operação na conta/título → recebe o valor CETIP integral.
   - Mais de uma operação → cada uma recebe `TRUNC(qt × PU, 2)` e a sobra de centavos vai para a maior, fechando exatamente com o total da CETIP.
5. **Controle** → compara `qt × PU` e a quantidade da posição com a CETIP.
6. **Saída** → grava o `MTCAIXA.txt`.

| Status          | Significado |
|-----------------|-------------|
| `OK`            | Quantidade e valor batem |
| `DIVERGE QTD`   | Quantidade da posição ≠ quantidade da CETIP (**principal alerta**). A linha é gravada mesmo assim, com o valor da CETIP |

# CÓDIGO ATUAL (`gerar_mtcaixa_premio.py`)

```python
"""
Gera MTCAIXA.txt de PAGAMENTO DE PRÊMIO (lançamento 960)
1) Lê o arquivo de operações da CETIP e filtra o evento
2) Monta a query de posição (LZ) com os títulos encontrados e executa no Athena
3) Cruza Conta CETIP + Título x CD_CETIP + codigo_clearing
4) Valor lançado = Valor da CETIP (rateado por operação quando houver mais de uma)
   Data lançamento/liquidação = Data Liquidação do arquivo da CETIP
   Conta qt * PU apenas como CONTROLE (quantidade e valor)
"""
import pandas as pd
from decimal import Decimal, ROUND_DOWN
from pathlib import Path

DSN_ATHENA   = "SEU_DSN_AQUI"
ARQ_CETIP    = r"EXEMPLO_OP_CETIP.txt"
ARQ_SAIDA    = r"MTCAIXA.txt"
TIPO_EVENTO  = "PAGAMENTO DE PREMIO"   # comparado sem acento
COD_LANC     = "960"

DB = "db_corp_custodiademercadodecapitais_hubdadosinvesmentservices_sor_01"


# ------------------------------------------------------------------ utilitários
def ler(arq, sep):
    for enc in ("utf-8-sig", "cp1252"):
        try:
            return pd.read_csv(arq, sep=sep, dtype=str, encoding=enc)
        except UnicodeDecodeError:
            pass


def sem_acento(s):
    return (s.str.upper().str.normalize("NFKD")
             .str.encode("ascii", "ignore").str.decode("ascii").str.strip())


def so_digitos(s):
    # trata int/float/str vindos do ODBC (ex.: 23854006, 23854006.0, '2385400-6')
    return (s.astype(str).str.strip()
             .str.replace(r"\.0+$", "", regex=True)
             .str.replace(r"\D", "", regex=True))


def trunc2(x):
    return Decimal(str(x)).quantize(Decimal("0.01"), rounding=ROUND_DOWN)


# ------------------------------------------------------------------ Athena
def executar_query_athena(query: str) -> pd.DataFrame | None:
    """Executa a query via ODBC (DSN configurado na máquina) e devolve um DataFrame."""
    import pyodbc  # aqui dentro: a Central abre mesmo sem o driver instalado
    try:
        connection = pyodbc.connect(f"DSN={DSN_ATHENA}", timeout=30)
        cursor = connection.cursor()
        cursor.execute(query)
        columns = [column[0] for column in cursor.description]
        results = cursor.fetchall()
        cursor.close()
        connection.close()
        return pd.DataFrame.from_records(results, columns=columns)
    except pyodbc.Error as e:
        print("Erro ao conectar ou executar a query:", e)
        return None


def montar_query_posicao(titulos: list[str]) -> str:
    lista = ", ".join(f"'{t}'" for t in sorted(set(titulos)))
    return f"""
WITH datas AS (
    SELECT DISTINCT data_posicao
    FROM {DB}.tbih3_posicao_fundo_renda_fixa
    WHERE data_posicao >= CAST(current_date - INTERVAL '15' DAY AS TIMESTAMP)
      AND data_posicao <  CAST(current_date AS TIMESTAMP)
      AND sigla_sistema_origem = 'LZ'
      AND indicador_publico_privado = 'I'
),
janela AS (
    SELECT data_posicao,
           ROW_NUMBER() OVER (ORDER BY data_posicao DESC) - 1 AS dias_parado
    FROM datas
),
ultima AS (
    SELECT P.sigla_carteira, MAX(P.data_posicao) AS data_posicao
    FROM {DB}.tbih3_posicao_fundo_renda_fixa P
    JOIN janela J
      ON J.data_posicao = P.data_posicao
     AND J.dias_parado <= 5
    WHERE P.sigla_sistema_origem = 'LZ'
      AND P.indicador_publico_privado = 'I'
    GROUP BY P.sigla_carteira
),
base AS (
    SELECT
      POSICAO.sigla_sistema_origem AS codigo_sistema,
      POSICAO.sigla_carteira,
      CAD_CART.codigo_administrador AS CD_ADM,
      CAD_CART_SAC.codigo_cetip AS CD_CETIP,
      POSICAO.data_posicao,
      J.dias_parado,
      TRIM(POSICAO.codigo_operacao) AS codigo_operacao,
      LASTRO.codigo_lastro,
      LASTRO.tipo_ativo,
      POSICAO.indicador_publico_privado,
      POSICAO.data_aquisicao,
      data_vencimento,
      POSICAO.codigo_indexador,
      LASTRO.percentual_sobre_indexador,
      POSICAO.indicador_titulo,
      LASTRO.codigo_clearing,
      POSICAO.codigo_ativo_lastro,
      POSICAO.quantidade_disponivel,
      POSICAO.quantidade_bloqueada,
      POSICAO.quantidade_total,
      LASTRO.indicador_mtm,
      ROW_NUMBER() OVER (
          PARTITION BY POSICAO.sigla_sistema_origem,
                       POSICAO.sigla_carteira,
                       POSICAO.data_posicao,
                       TRIM(POSICAO.codigo_operacao),
                       POSICAO.codigo_ativo_lastro
          ORDER BY POSICAO.data_democratizacao DESC
      ) AS rn
    FROM {DB}.tbih3_posicao_fundo_renda_fixa POSICAO
    JOIN ultima U
      ON POSICAO.sigla_carteira = U.sigla_carteira
     AND POSICAO.data_posicao   = U.data_posicao
    JOIN janela J
      ON J.data_posicao = U.data_posicao
    JOIN {DB}.tbih3_cadastro_carteira_codigo CART_COD
      ON POSICAO.sigla_carteira = TRIM(CART_COD.sigla_carteira)
     AND POSICAO.sigla_sistema_origem = CART_COD.sigla_sistema_origem
    JOIN {DB}.tbih3_cadastro_ativo_lastro_renda_fixa LASTRO
      ON POSICAO.codigo_ativo_lastro = LASTRO.codigo_lastro
     AND POSICAO.sigla_sistema_origem = LASTRO.sigla_sistema_origem
    JOIN {DB}.tbih3_cadastro_carteira CAD_CART
      ON TRIM(CAD_CART.sigla_carteira) = POSICAO.sigla_carteira
     AND POSICAO.sigla_sistema_origem = CAD_CART.sigla_sistema_origem
    JOIN {DB}.tbih3_cadastro_carteira_complemento_sac CAD_CART_SAC
      ON POSICAO.sigla_carteira = TRIM(CAD_CART_SAC.sigla_carteira)
     AND POSICAO.sigla_sistema_origem = CAD_CART_SAC.sigla_sistema_origem
    WHERE POSICAO.sigla_sistema_origem = 'LZ'
      AND POSICAO.indicador_publico_privado = 'I'
      AND LASTRO.codigo_clearing IN ({lista})
)
SELECT *
FROM base
WHERE rn = 1
ORDER BY dias_parado DESC, sigla_carteira
"""


# ------------------------------------------------------------------ processo
def main():
    # 1) CETIP -> eventos do tipo desejado
    cetip = ler(ARQ_CETIP, "\t")
    cetip.columns = cetip.columns.str.strip()
    cetip = cetip.apply(lambda s: s.str.strip())
    ev = cetip[sem_acento(cetip["Tipo Operação"]) == TIPO_EVENTO].copy()
    if ev.empty:
        print(f"Nenhum evento '{TIPO_EVENTO}' no arquivo da CETIP.")
        return
    ev["conta"] = so_digitos(ev["Conta"])
    ev["PU"] = ev["PU"].astype(float)
    ev["Quantidade"] = ev["Quantidade"].astype(float)
    ev["Valor"] = ev["Valor"].astype(float)
    ev = ev[["conta", "Conta", "Título", "PU", "Quantidade", "Valor", "Data Liquidação"]]

    # 2) Posição via Athena
    query = montar_query_posicao(ev["Título"].tolist())
    pos = executar_query_athena(query)
    if pos is None or pos.empty:
        print("Query de posição não retornou dados.")
        return
    pos.columns = pos.columns.str.lower()   # Athena devolve alias em minúsculo
    for c in ("sigla_carteira", "codigo_operacao", "codigo_clearing", "tipo_ativo"):
        pos[c] = pos[c].astype(str).str.strip()
    pos["conta"] = so_digitos(pos["cd_cetip"])
    pos["quantidade_total"] = pos["quantidade_total"].astype(float)
    pos = pos[pos["quantidade_total"] > 0]

    base = pos.merge(ev, left_on=["conta", "codigo_clearing"],
                     right_on=["conta", "Título"], how="inner", validate="m:1")
    base = base.sort_values(["Conta", "Título", "quantidade_total", "codigo_operacao"],
                            ascending=[True, True, False, True]).reset_index(drop=True)

    # Valor de controle por operação: TRUNC(qt * PU, 2)
    base["valor_calc"] = [trunc2(q * p) for q, p in zip(base["quantidade_total"], base["PU"])]

    # Valor lançado = CETIP. Com 1 operação -> valor CETIP direto.
    # Com várias -> qt*PU em cada uma e a sobra de centavos vai na maior operação,
    # garantindo que a soma bata exatamente com a CETIP.
    base["valor"] = base["valor_calc"]
    for _, g in base.groupby(["Conta", "Título"]):
        total_cetip = Decimal(str(g["Valor"].iloc[0])).quantize(Decimal("0.01"))
        if len(g) == 1:
            base.loc[g.index[0], "valor"] = total_cetip
        else:
            base.loc[g.index[0], "valor"] = total_cetip - sum(g["valor_calc"].iloc[1:])

    # 3) Conferência / controle posição x CETIP
    chk = base.groupby(["Conta", "Título"]).agg(
        qt_pos=("quantidade_total", "sum"), qt_cetip=("Quantidade", "first"),
        valor_calc=("valor_calc", "sum"), valor_cetip=("Valor", "first"),
        valor_lancado=("valor", "sum"), n_oper=("codigo_operacao", "count")).reset_index()
    chk["dif_qt"] = chk["qt_pos"] - chk["qt_cetip"]
    chk["dif_valor"] = (chk["valor_calc"].astype(float) - chk["valor_cetip"]).round(2)
    chk["status"] = "OK"
    chk.loc[chk["dif_valor"].abs() > 0.01 * chk["n_oper"], "status"] = "DIVERGE VALOR"
    chk.loc[chk["dif_qt"] != 0, "status"] = "DIVERGE QTD"
    print("CONTROLE:\n", chk.drop(columns="n_oper").to_string(index=False))
    if (chk["status"] != "OK").any():
        print("\n*** ATENÇÃO: há divergência entre posição e CETIP - verificar antes de importar.")

    chave_ok = set(zip(base["conta"], base["Título"]))
    faltam = ev[[(c, t) not in chave_ok for c, t in zip(ev["conta"], ev["Título"])]]
    if not faltam.empty:
        print("\n*** Evento na CETIP SEM posição (não lançado):\n",
              faltam[["Conta", "Título", "Quantidade", "Valor"]].to_string(index=False))

    base = base.sort_values(["sigla_carteira", "codigo_clearing", "codigo_operacao"])

    # 4) MTCAIXA (18 colunas, tab, cp1252, CRLF)
    linhas = []
    for i, r in enumerate(base.to_dict("records"), start=1):
        dt = pd.to_datetime(r["Data Liquidação"], dayfirst=True).strftime("%d/%m/%Y")
        v = f"{r['valor']:.2f}"
        desc = f"PAGAMENTO DE PRÊMIO {r['tipo_ativo']} {r['codigo_clearing']} {r['codigo_operacao']}"
        linhas.append("\t".join([str(i), dt, r["sigla_carteira"], "MT", COD_LANC, desc, v,
                                 "", "", "", "N", dt, "N", "N", "REAL", v, "", "5"]))

    if linhas:
        Path(ARQ_SAIDA).write_text("\r\n".join(linhas) + "\r\n", encoding="cp1252")
    print(f"\n{len(linhas)} linhas gravadas em {ARQ_SAIDA}")

    main()
```
